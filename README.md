# MOBIL OFL

Mobil cihazlar icin gelistirilen, okulda gecen first person co-op dedektiflik oyunu prototipi.

## Oyun Fikri
- Mekan: okul
- Tur: first person investigation
- Hedef platform: mobil
- Oyuncu sayisi: 1-4 online co-op
- Ana hedef: okulda islenen sucu deliller, NPC sorgulari ve takim notlari ile ortaya cikarmak

## Projede Olan Sistemler
- Vaka, delil ve supheli sistemi
- Delil toplama ve NPC sorgu akisi
- Vaka dosyasi / notebook arayuzu
- Takim notlari sistemi
- Mini harita ve dunya marker'lari
- Sonuc ekrani
- Mobil kontrol arayuzu
- Online prototip altyapisi
- Auto scene setup editor araci

## Kurulum
Unity surumu:
- `6000.4.3f1`

Sahneyi hizli kurmak icin Unity icinde:
- `Mobil OFL > Setup > Auto Setup Investigation Scene`
